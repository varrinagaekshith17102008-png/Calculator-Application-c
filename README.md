#  Safe Menu Calculator in C

A simple, interactive, and user-friendly calculator developed in the C programming language. This project demonstrates the use of control statements, loops, input validation, and error handling while providing a menu-driven interface.

##  Project Overview

The **Safe Menu Calculator** performs basic arithmetic operations through an interactive menu. It validates user input, prevents common runtime errors such as division by zero, and allows users to perform multiple calculations without restarting the program.

This project was developed as part of my C programming practice to strengthen problem-solving skills and write cleaner, more reliable code.



##  Features

*  Addition
*  Subtraction
*  Multiplication
*  Division
*  Input validation for numeric values
*  Invalid menu choice handling
*  Division by zero protection
*  Repeat calculations without restarting the program
*  User-friendly menu interface

##  How to Run

1. Clone this repository.
2. Open the project in Visual Studio Code or any C IDE.
3. Compile the program.

```bash
gcc calculator.c -o calculator
```

4. Run the executable.

```bash
./calculator
```

*(On Windows, run `calculator.exe` after compilation.)*
